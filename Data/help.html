Infinity Harmony Help

Choose a quick guide or a detailed ABC notation reference.

Quick guide

  1. Set the song title, time signature, tempo, and number of voices at the top.
  2. Add a measure with + Measure. Select a note field, then enter notes with the piano, number keys, or by typing ABC notes.
  3. Use Whole, Half, ¼, ⅛, 1/16 to choose a note length. Dot adds half the selected length. Use Rest for silence.
  4. Press Tab in a note field to move through the voice note fields. Press T to jump to lyrics. In lyrics, Tab returns to the matching notes.
  5. Use the controls row to choose note entry mode, set which number means 0, change appearance, and show or hide the score preview.
  6. Press Space while holding a number key to raise that note by a half step. Press Backspace in a keyboard entry mode to remove the last note token.

Lyrics and extra notation

Use a hyphen between lyric syllables, such as Hap-py birth-day. You can also type accidentals like ^F for F sharp or _B for B flat, and slur marks ( and ).

If an advanced ABC symbol does not fit naturally in the editor, import a plain text .abc file. The detailed guide shows the format.

Detailed notation reference

The editor’s voice boxes accept ABC note tokens. The application uses L:1/4, so a quarter note is one beat. Put spaces between note tokens; the editor adds bar lines from the selected time signature.

Pitch and octave

  • C D E F G A B are the middle octave, with uppercase C as middle C.
  • Lowercase notes, such as c, are one octave higher. Add apostrophes to raise further: c'.
  • Add commas to lower notes: C, is one octave lower; C,, is two octaves lower.
  • ^F raises F by a semitone, _B lowers B, and =F cancels an accidental.

Lengths, rests, and phrasing

A number after a note changes its length relative to a quarter note. A slash divides the length: C2 is a half note, D/2 an eighth, E/4 a sixteenth, and F3/2 a dotted quarter. A bare note such as G is a quarter note.

Use z for a rest, with the same length forms: z2, z/2. Parentheses mark a slur: (C D E). A hyphen after a note ties it to the next note, as in C- C. A bar line | can be typed, but the editor recalculates regular bars automatically.

Manual ABC files

For features beyond the editor controls, create a plain text file with an .abc extension and import it through Songbook → Import Project Files. A basic four-part example:

X:1
T:Example
M:4/4
L:1/4
Q:1/4=120
K:C
%%score (1 2) (3 4)
V:1 clef=treble
C D E F | G2 z2 |
w: Hap-py birth-day
V:2 clef=treble
E F G A | B2 z2 |
V:3 clef=bass
C, D, E, F, | G,2 z2 |
V:4 clef=bass
G,, A,, B,, C, | D,2 z2 |

X: identifies the tune; T: sets its title; M: sets meter; L: sets the default note length; Q: sets tempo; K: sets the key; and each V: starts a voice. w: attaches lyrics to the preceding voice.

Advanced ABC features

  • Chords: [CEG] plays notes together.
  • Tuplets: (3CDE fits three notes into the time normally occupied by two.
  • Broken rhythm: C>D lengthens C and shortens D; C<D does the reverse.
  • Repeats and endings: |:, :|, and [1 / [2.
  • Inline fields can change settings mid-tune, for example [K:G] or [M:3/4].

These advanced forms follow ABC notation, but automatic bar counting is designed for individual notes and rests. For chords, tuplets, or complex rhythm, use a complete ABC file so the notation is kept together. For ABC reference, see ABC Standard v2.1.
